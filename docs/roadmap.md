# Roadmap

## M0 — Engineering operating system
Reproducible Python tooling, typed identity model, governance, CI, documentation, and incidents.

## M1 — Benchmark contract
JSON schema, fixture catalog, seeded failure definitions, and corpus validation.

## M2 — Deterministic runner
Clean worktrees, command capture, repository hashes, artifacts, and immutable run records.

## M3 — False-success evaluation
Independent verifier input, deterministic classifications, and executor/verifier disagreement.

## M4 — Recovery lineage
Parent run IDs, current-head semantics, checkpoint supersession, and crash reconciliation.

## M5 — Observability and public report
OpenTelemetry traces, aggregate metrics, raw JSON/CSV, and a reproducible multi-model report.
