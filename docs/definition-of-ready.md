# Definition of Ready

A task may enter implementation only when:

- [ ] The problem and user impact are clear.
- [ ] The expected outcome is observable.
- [ ] Non-goals are explicit.
- [ ] Allowed files and repositories are bounded.
- [ ] Dependencies and ordering are known.
- [ ] Verification commands are written before implementation.
- [ ] Risks, security concerns, and rollback are identified.
- [ ] The task is small enough for one implementation mission.
