# Definition of Done

A task is complete only when:

- [ ] The implementation matches the issue outcome and non-goals.
- [ ] Unit and integration tests pass.
- [ ] Lint, formatting, typing, coverage, and build checks pass.
- [ ] Regression tests cover every repaired defect.
- [ ] Documentation and ADRs are updated.
- [ ] Evidence and final diff were reviewed independently.
- [ ] No unresolved mutation or recovery intent remains.
- [ ] CI passes on the pull request.
- [ ] The change is merged and included in a release or milestone record.
